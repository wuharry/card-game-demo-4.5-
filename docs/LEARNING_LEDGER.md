# 學習債清單(Learning Ledger)

> **這是什麼**:逃生艙 / AI 代工做出來、但 Harvey(Godot 新手)未必理解的觀念總帳。
> 建帳日 2026-07-06;主帳範圍 = commit `cbb80f4`…`f11931d`(Harvey 指定的逃生艙區間)。
>
> **給 agent 的使用規則**:
> 1. **出題時機**:只在 Harvey 主動說「**還債** / **考我** / **考我 §N** / **我要學會 X** / 我要複習 / 學以前的東西」時啟動,平常別轟炸(同 CLAUDE.md §6)。
>    **但「查等級」不受此限**——每次複雜任務分派前都要查(CLAUDE.md §1a),只是查完不一定出題。
> 2. **怎麼挑**:優先挑等級最低、最久沒驗的;超級新手 → 優先「第一梯隊·地基五柱」。
>    **一次 1 個概念**,該概念最多 2–3 題(不是一次考 3 個不同概念)。
> 3. **考完就記帳**:更新等級欄(附日期+判定依據)。答不出 → 照 CLAUDE.md §3 換方式教,教完維持原級、下次再驗,**不要教完就直接升級**。
> 4. **之後每次逃生艙任務收尾**:把新產生的觀念補進本表(預設「初階/未驗」)。

## 等級定義(Harvey 自訂)

| 等級 | 意義 |
|---|---|
| **初階** | 需要 agent 主動指導、主動提醒、或稍微修正才能運用 |
| **中階** | agent 問他能很好地回答,有不錯的熟悉度;**且能自己動手重建那段**(光答得好還不算) |
| **高階** | 能處理延伸題;做大任務完全不需幫忙;以前會卡的地方現在不卡 |

**升級判準**(2026-07-28 對齊 CLAUDE.md §6 鐵則:只有「**示範得出來**」才升等,光聽懂、光點頭不算):

- **初階 → 中階**:能答出「是什麼 + 為什麼這樣設計」**且**自己動手重建那段(§6 步驟 1 + 2)。
  單靠口頭答對**不升**——那只是四步的第一步。
- **中階 → 高階**:通過**新情境**的遷移題(§6 步驟 3),或在大任務裡自己把觀念用出來。

> 舊版判準寫「初階→中階 = 被問能答出『是什麼 + 為什麼』」,與 CLAUDE.md §6 鐵則衝突
> (§6 明文那只是第一步「預測」)。依 §6 為準修正——能複述是 fluency,能重建才是實力。
