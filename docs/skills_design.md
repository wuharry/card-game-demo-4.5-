## 0. 設計核心:看得到的動作 = 用得到的招

素材包每隻角色自帶多張動畫表,技能系統直接以動畫為錨,**不憑空發明沒有動畫的招**:

| 動畫表 | 對應行動 | 費用 |
|---|---|---|
| `Attack01` | **普通攻擊**(§4 雙向傷害交換) | **免費**,每回合 1 次 |
| `Attack02` | **主動技能**(預設;個別單位可指定專屬表) | 消耗魔力 |
| `Attack03` | **保留欄位**(升級技 / 進化用,暫不啟用) | — |
| `Block` | 被動【鐵壁】/ 守護觸發的受擊動畫 | — |
| `Summon` | 登場動畫(入槽時可取代縮放彈出);骷髏家族兼【不滅】復活動畫 | — |
| `Hurt` / `Death` | 受擊 / 陣亡回饋(戰鬥系統動工時接) | — |

## 1. 動畫盤點結論(2026-07-09 實測檔案清單)

- **全員皆有** `Attack01`(或單一 `Attack`)→ 普攻無例外。
- **有 `Attack02`(可配主動技)**:24 隻中 22 隻。**例外:牧師、骷髏弓手**(只有單一攻擊表)。
  - 牧師改用專屬 `Heal` 表配治療技 → 依然有主動技。
  - 骷髏弓手 → **無主動技**,靠被動與數值補(白板堆料)。
- **有 `Attack03`(保留)**:斧手、重甲獸人、菁英獸人、巨劍骷髏、騎士、聖殿騎士、槍騎兵、獸人騎手、士兵、劍士、熊人。
- **有 `Block`**:重甲獸人、騎士、聖殿騎士、獸人騎手、骷髏兵。
- **有 `Summon`**:骷髏兵、重甲骷髏、巨劍骷髏、骷髏弓手、死靈法師。
- **法師系特效版**:巫師 / 牧師 / 死靈法師有 `(With magic effects)` 合成表——技能動畫直接用合成版,不必另疊特效層。

### 命名地雷(get_anim_sheet 的呼叫端要知道)

| 地雷 | 處置 |
|---|---|
| 蝙蝠沒有 `Idle`(用 `Flying`) | standee 已指向 Flying;推兄弟表用「最後一個底線」切,不受影響 |
| `Swordsman_Attack3`(不是 03) | 劍士的 anim 欄填 `"Attack3"` |
| `Necromancer_DEATH` 全大寫 | 接死亡動畫時填 `"DEATH"` |
| 牧師/骷髏弓手只有 `Attack`(無 01) | 普攻 anim 欄填 `"Attack"` |
| 特效合成版檔名含括號空格 | anim 欄填完整後綴,如 `"Heal(With magic effects)"` |
| 特效表可能非正方形格 | 接動畫時先驗 hframes(寬 ÷ 高)是否整除 |

## 2. 資料層合約(戰鬥系統要實作的全部詞彙)

刻意壓小:**5 種修飾 × 3 種效果 × 5 種狀態**,戰鬥系統(README 待辦 #5)只要吃這些。

- `Kind`:`ENHANCED_ATTACK` 強化攻擊(佔普攻)/ `INDEPENDENT_ATTACK` 獨立攻擊(額外攻擊,召喚當回合不可用)/ `NON_ATTACK` 非攻擊(§6)
- `Modifier`(攻擊型):`SPREAD_3` 橫掃三路(§4.1)/ `PIERCE` 貫穿前後排 / `DOUBLE` 連擊兩次 / `LIFESTEAL` 吸血
- `Effect`:`HEAL` / `APPLY_STATUS` / `SUMMON`
- `Target`:`SELF` / `ALLY` / `LANE_ENEMY`
- `Status`:對齊 §9(灼燒≤2 回合、凍結、中毒、夜幕、鍛強)

## 4. 設計理由(想過才這樣配)

- **骷髏家族全員【不滅】**:四隻都自帶 `Summon`(從地裡爬出來)動畫 = 現成的復活演出。
  家族識別 > 個體平衡;復活後 HP = 1、每場一次(§8),不會失控。
- **【鐵壁】是新增關鍵字**(已補進 README §8):每回合首次受到的從者攻擊傷害 −1,
  觸發播 `Block` 動畫——有格擋動畫的坦克(騎士、重甲獸人)才配得,動畫決定能力。
- **修飾各有歸屬**:橫掃=迴旋斧、貫穿=長槍、連擊=雙刀流劍士、吸血=蝙蝠/狼人/血肉——
  一招一個視覺聯想,玩家看動畫就能猜效果。
- **「power +2」出現多次是刻意的**:強化攻擊是麵包奶油(爐石也一堆 +2),
  差異化留給費用(獸人 1 費超值)與被動;之後平衡再各自調。
- **compound(雙修飾)只給最貴的卡**:血之狂宴(6 費 8 攻,+2 且吸血)是曲線頂端的招牌,
  下不放寬,避免效果組合爆炸。
- **控場只給兩隻**:騎士(命中才凍)與熊人(指定凍)——凍結很強(§9:斷攻擊+斷技能),
  入口收窄方便平衡。
- **費用曲線**:技能費 1~3。低費單位技能費 ≤ 召喚費(死了再拉一隻不心疼);
  高費單位技能費 3 封頂(魔力上限 7,要留召喚空間)。
