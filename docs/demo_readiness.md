# Demo 完成度與戰鬥手感計畫（2026-09-12）

## 結論

單人核心玩法已能完整對局，但公開 Demo 還缺「效果辨識、第一次上手、固定牌組、音量控制、發佈驗收」五個關卡。連線不列入本輪門檻；先把每次操作做成玩家看得懂、聽得懂、能預測結果的完整回饋，再增加更多卡片。

```text
玩家操作 → 先兆（選取／瞄準）→ 動作（卡牌或角色動畫）→ 結果（VFX＋SFX＋數字）→ 狀態落地
```

目前已有 132 張卡、完整單人 AI、13 個通用 SFX、角色攻擊／受傷／死亡動畫、飄字、通用傷害粒子及回魔洞演出。主要問題是多種規則共用同一個 `SPELL_CAST` 與 `FxBurst`，火焰、冰凍、治療、護盾、反制和伏印在畫面上缺少各自的辨識特徵。

## 建議接法

不要為 132 張卡各寫一段特效程式；先依效果家族共用，再讓少數傳說卡覆寫。

```text
BattleManager 結算
        ↓（傷害、治療、狀態、召喚等結果）
CardManager 發出演出事件
        ↓
FxDirector 依 effect／status／modifier 選 FxProfile
        ├─ AnimatedSprite3D：像素幀動畫
        ├─ FxBurst：補火花、泛光與空間感
        └─ Sfx：播放對應音效家族
```

`SkillData.effect`、`status`、`modifier` 已能決定大部分效果；只有需要特殊演出的卡才新增可選 `vfx_id`。例如「火焰爆裂」由 `status=BURN` 自動選火焰施法＋火焰命中，「赤曜古龍」再用 `vfx_id` 覆寫成較大的傳說級版本。

| 效果家族 | 最低演出 | 可重用卡片 |
|---|---|---|
| 斬擊／穿刺／鈍擊 | 攻擊軌跡＋不同命中聲＋短促火花 | 普攻與物理技能 |
| 火／冰／雷／毒／暗影 | 施法先兆＋命中特效＋各自音色 | 元素秘術、狀態技能 |
| 治療／護盾／增益 | 由下往上亮起；不得播放受擊動畫 | 治療、鍛強、鐵壁 |
| 召喚／復活／死亡 | 落地或聚合＋短停頓＋結果音 | 戰吼、亡者召集、不滅 |
| 瞬咒／伏印 | 揭牌／破裂／抵銷三段，讓守方介入可見 | 反制窗口、宿主伏印 |
| 回魔／棄牌／爆牌 | 卡牌吸入黑洞＋魔力飛向 HUD＋入帳聲 | 丟牌回魔、滿手燒牌 |

像素效果以 `nearest` 過濾、固定世界尺寸與固定 FPS 播放；現有 `FxBurst` 保留為第二層火花，不拿它取代主效果。`reduce_motion` 開啟時改播首尾兩幀、停用鏡頭震動與大幅縮放。

## 可玩性與對局深度提升（對齊爐石／闇影詩章 2 體驗差距）

目前原型具備完整的 5×2 前後排、路線阻擋打臉、丟牌回魔與瞬咒反制等底層規則，但「可玩性與策略反饋」仍與商業 CCG 有明顯差距。核心改善項目分為「操作回饋層」與「底層機制硬傷」兩大軸度：

#### A. 操作反饋層（Game Feel & Juice）
1. **牌組體系化與套路配合（解決隨機大雜燴）**：
   - **痛點**：目前由 132 卡池隨機抽 60 張混編，玩家無法依策略組牌，抽到 10 費高階秘術卻無前期濾牌或回魔元件配合，只能卡死在手牌。
   - **解法**：建立「快攻灼燒」與「死靈召喚」兩副互克的主題套牌，驗證流派連鎖。
   - **死靈設計草案（2026-09-18）**：主動技能、死靈化／召喚／攻防法術與待定規則見 [死靈流派構想草案](necromancy_archetype.md)；尚未定案或實作。
2. **戰鬥打擊感與手感重量**：
   - **痛點**：從者攻擊時原地播放幀動畫、目標頭上飄出數字，缺少實體肉搏碰撞力，整體體驗偏向「數值試算表」。
   - **解法**：卡牌攻擊加入向目標位移拉扯衝撞（Tween）、命中短暫停頓（Hit Stop）、受擊卡牌受力晃動、致死重擊鏡頭微震與打擊重音。
3. **戰場博弈深度顯性化**：
   - **痛點**：前後排阻擋與嘲諷守護範圍主要靠玩家自記規則，容易漏看文字而忽略防守站位優勢。
   - **解法**：透過 UI 視覺高亮「阻擋路線」與「嘲諷守護範圍」，強化瞬咒反制與伏印陷阱心理戰提示。

### B. 底層機制硬傷（Systemic Gameplay Issues）
4. **資源循環乾涸（防止中後期「抽一打一」垃圾時間）**：
   - **痛點**：每回合固定抽 1 張且「丟牌回魔」需倒扣手牌並有隔回合冷卻，導致第 5–6 回合手牌枯竭，對局退化成無選擇的垃圾時間。
   - **解法**：引入「入場/亡語抽牌」與回合開始的「二選一抽濾」，維持手牌常駐 3–5 張以保留決策空間。
5. **5×2 卡槽空間死鎖（防止肉盾塞車形成泥巴仗）**：
   - **痛點**：單位入場後永久釘死在格子上，前排若被雙方高血肉盾（如 1 攻 8 血帶鐵壁）堵住，同路後排大怪既無法攻擊對手本體也無法前進，戰局停滯。
   - **解法**：加入「主動犧牲／卡槽回收」指令，或允許消耗少許魔力在「同路前後排換位」，釋放攻擊路徑。
6. **後手補償機制缺失（平抑先手滾雪球優勢）**：
   - **痛點**：先手永遠先召喚、先攻擊、先到達高費；後手魔力與場面雙重落後且無補償，勝負在擲骰/猜拳時就決定大半。
   - **解法**：後手開局多抽 1 張牌，並給予 1 張一次性「0 費暫時魔力幣」，彌補後手被動解場的劣勢。
7. **數值過度線性對稱（缺乏超模神抽刺激感）**：
   - **痛點**：卡牌效果嚴格遵循「N 費做 N 點數值」，缺乏商業 CCG 透過前置條件引爆的「費用魔術 (Mana Cheat)」與全場逆轉 (Swing Turn)。
   - **解法**：設計「墓場達標費用減為 0」或「消滅全場從者並反哺生命」的特異卡，營造絕境逆轉的多巴胺高潮。
8. **3D 透視與遠端可讀性負擔**：
   - **痛點**：36° 俯角透視使敵方後排尺寸縮小 40%，且血量 Label3D 容易被前排角色頭頂模型遮擋，長時間操作容易視覺疲勞。
   - **解法**：提供微透視/平行正交切換，點選卡牌時呼叫正面懸浮無遮擋聚焦層。
9. **抽卡系統階段性定位（Demo 階段排除）**：
   - **痛點/誤區**：過早開發開包抽卡只會稀釋精力，且在對局不好玩時抽卡無法提供興奮感。
   - **解法**：Demo 階段專注核心戰鬥與固定套牌，抽卡盲盒延後至戰鬥達到 80 分後再進行。

## 建議製作順序

1. **固定套牌與過牌成型**：從 132 張卡池中抽取配置，建立「快攻灼燒」與「死靈召喚」兩副固定牌組，並加入過牌機制取代全隨機發牌。
2. **後手魔力幣補償**：實作後手額外手牌與 0 費暫時魔力道具，平抑先後手勝率失衡。
3. **攻擊位移與打擊回饋**：加入 Card 攻擊向目標衝撞位移 Tween、命中受力晃動與重音，提升核心操作爽感。
