# 42 張從者對齊 Pack01/02 設計稿 — 翻譯表

> 建檔 2026-08-10。**決策來源**:Harvey 拍板「以清單為準,規格與資料層跟著擴」+「保留 5 路線,把清單效果翻譯進來」。
> 規則錨點仍是 [README.md](../README.md) Gameplay Spec;本文件是「清單 → 現行規則模型」的**翻譯合約**。
> 技能配置的舊版基準見 [skills_design.md](skills_design.md)(該檔的 24 卡表已被本文件取代;仍有效的是動畫盤點與命名地雷兩節)。

## 0. 已拍板的四條前提

| # | 決策 | 理由 |
|---|---|---|
| 1 | **保留 5 路線直線攻擊**,不改成自由選目標 | 清單是爐石模型寫的;5 路線下「飛行越過嘲諷打後排」等定義空轉。README §8.1 的守護型嘲諷才有作用 |
| 2 | **這輪不做第二主動技**(Attack03) | `active_skill` 同時是秘術/靈裝/伏印的效果載體(31 個呼叫點 / 7 檔),改陣列會讓 57 張卡為了 10 張付代價。10 張各挑一個技 |
| 3 | **防禦力 −1 → ATK −1** | §4.2 明訂數值只有 ATK/HP;加第三個數值要動卡面/HUD/AI/連線,買到的深度不值 |
| 4 | **50% 機率復活 → 【不滅】** | 連線對戰下隨機要同步 RNG seed,否則兩台帳分岔。【不滅】語意幾乎相同但確定性 |

**這輪實作範圍**:護盾 + 戰吼兩個機制。荊棘(受擊反傷)、觸發式被動(友方死亡/造成傷害時)下輪。

## 1. 資料層要加的東西(7 項)

| 項目 | 位置 | 說明 |
|---|---|---|
| `Effect.SHIELD` | `skill_data.gd` 枚舉**尾巴** | 護盾;用 `amount` 當盾值。枚舉只能往尾加(.tres 存 int) |
| `Target.ADJACENT_ALLIES` | `skill_data.gd` 枚舉尾巴 | 騎士【守護】用;可直接複用 `_adjacent_lane_units()` |
| `Target.ALLY_HERO` | `skill_data.gd` 枚舉尾巴 | 聖殿騎士/牧師的「恢復己方英雄」 |
| `Modifier.SPREAD_ALL` | `skill_data.gd` 枚舉尾巴 | 「對敵方所有單位」;和 `SPREAD_3` 同一段展開 |
| `Status.WEAKEN` | `skill_data.gd` 枚舉尾巴 | ATK −1(承接前提 #3);和 `FORGE`(+2)成對 |
| `CardData.battlecry: SkillData` | `card_data.gd` 新 `@export` | **復用 SkillData**,不開新型別。預設 `null` = 零遷移,現有 57 張一張不用改 |
| `Card.shield: int` | `card.gd` 執行期欄位 | 和 `current_hp` 同族:**存節點不存 CardData**,否則全場同名卡共用一面盾 |

**接線點**(兩個 choke point,不新開):
- 護盾 → `_deal_damage()`:夜幕減半 → 鐵壁 −1 → **護盾吸收** → 扣血
- 戰吼 → `mark_summoned()`:伏印觸發已經掛這裡,同一條必經之路

## 2. 翻譯規則(套用到全部 42 張)

| 清單寫法 | 翻成 |
|---|---|
| 對敵方單位造成 X 傷害 | `INDEPENDENT_ATTACK`,`power = X` |
| 對敵方**最多 2 個**單位各 X | `Modifier.SPREAD_3`(主目標 + 左右相鄰路,共 3)⚠ 近似 |
| 對敵方**所有**單位 X | `Modifier.SPREAD_ALL`(新增) |
| 造成 X 傷害**兩次** | `Modifier.DOUBLE` ✅ 精確 |
| 造成 X 並恢復自身**等量** | `Modifier.LIFESTEAL` ✅ 精確 |
| 造成 X 並恢復自身 N(N≠X) | `Modifier.LIFESTEAL` ⚠ 近似(回的是實際傷害) |
| 穿透至後方單位 | `Modifier.PIERCE` ✅ 精確(後排確實站得了從者) |
| 使其**無法行動**一回合 | `Status.FREEZE` ✅ 精確 |
| 使其**無法使用技能**一回合 | `Status.FREEZE` ⚠ 偏強(§9 凍結連攻擊一起鎖) |
| 使自身攻擊力 +2 | `Status.FORGE` ✅ 精確(§9 鍛強正好 +2) |
| 使自身攻擊力 +1 / +3 | `Status.FORGE` ⚠ 近似(一律 +2) |
| 使其攻擊力 −1 | `Status.WEAKEN`(新增) |
| 獲得 N 點護盾 | `Effect.SHIELD` + `amount = N`(新增) |
| 恢復友方單位或英雄 N | `Effect.HEAL` + `Target.ALLY` / `ALLY_HERO` |
| 每回合開始受 1 點傷害 | `Status.POISON` ⚠(§9 中毒是回合**結束** −1;灼燒是每回合 2 點,更偏) |
| 召喚 / 分裂出 N/N | `Effect.SUMMON` + `summon_card` |
| 進場時 ⋯⋯ | `CardData.battlecry`(新增) |
| **隨機**一個單位 | 改成**正對面**(`Target.LANE_ENEMY`)——去隨機,同前提 #4 |

## 4. 需要 Harvey 拍板的 9 個判斷點

清單沒講清楚、或和現行規格對撞的地方。**先按「暫定」寫進 .tres,有異議再改**。

| # | 問題 | 暫定處置 |
|---|---|---|
| 1 | **清單完全沒提鐵壁/潛行/換位/突進**。嚴格照清單 → 這 4 個已定義(其中鐵壁、潛行已實作)的關鍵字變成**沒有任何一張卡在用**的死機制 | 保留現行配置:鐵壁給重甲獸人/騎士/黑鐵重騎(§8 限「有 `Block` 動畫者」,是素材事實),突進留給獸人騎兵 |
| 2 | **骷髏家族的【不滅】**清單寫「被動:無」,但骷髏兵/巨劍骷髏/骷髏弓手都有 `Summon` 復活動畫,§8 的不滅就是為它們設計的 | 保留【不滅】 |
| 3 | 聖殿騎士的**嘲諷**、狼人的**衝鋒**、血翼魔獸的**飛行**、惡魔守衛的**嘲諷**:清單沒有,現行有 | 保留(表中標 ⚠) |
| 4 | **惡魔守衛 召喚「1/1 小惡魔」——沒有這張卡** | 暫填 `summon_card = "bat"`(1/1/1 數值正好)。真要小惡魔得先有素材 |
| 5 | **骷髏弓箭手召 1/1、死靈法師召 2/2**,但只有一張 `skeleton.tres` | 兩者統一召 `skeleton`(2/2)。要分兩種得多一張卡 |
| 6 | **史萊姆分裂的「若血量 ≥ 2」條件**沒有對應機制 | 條件砍掉,無條件分裂 |
| 7 | **黑鐵重騎 的「死亡標記」**(標記目標,其死亡時回 3 血)——需要一套標記/延遲觸發框架 | 降級成 `LIFESTEAL`(當場回血)。要原效果得等觸發框架 |
| 8 | **地獄犬「全體 1 傷 + 全體 ATK −1」**:現行 `SPREAD_3` 的副目標只吃傷害、不吃附帶狀態 | WEAKEN 只上**主目標**。要全體上狀態得改 `_resolve_attack` 的副目標迴圈 |
| 9 | **蝙蝠的「吸血」在 1 血上限的單位身上是 no-op**(Harvey 2026-08-10 指出):`heal()` 一律被 `mini(上限, 現血+量)` 夾成 0,卡面等於印了一個永遠不會發生的效果 | 保留吸血的味道、把血吸到有意義的地方 → 改成**恢復己方英雄 1 點**(`Effect.HEAL` + `Target.ALLY_HERO`,沿用這輪為聖殿騎士/牧師加的目標型別,不必動 code)。技能名 吸血 → **噬血** |

## 5. 順帶修掉的既有問題

- **`&"遠射"` 是孤兒關鍵字**:只在 `archer.tres` 與 [skills_design.md](skills_design.md) 出現,README §8 表沒有、`src/` 零實作。本次移除。
  (若真想要「越過前排打後排」,那是 §4.1 的 `attack_range = BACKLINE`,需要另外實作,不是掛個字串就有。)
- **README §2 的「後排 = 伏印區」和實作對不上**:`enemy_ai.gd` 前排滿了會把從者放後排,伏印其實住在 `SideState.wards` 側帳。**README §2 已於 2026-08-10 訂正**。
